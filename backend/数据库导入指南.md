# 数据库导入指南

## 📋 概述

SmartGas Grid 项目使用 **SQLite** 作为数据库，数据库文件位于 `backend/data/smartgas.db`。

## 🚀 快速导入数据库

### 方法一：使用初始化脚本（推荐）

这是最简单的方法，会自动创建数据库表并导入初始数据。

#### 步骤：

1. **进入后端目录**
   ```bash
   cd backend
   ```

2. **安装 Python 依赖**（如果还没安装）
   ```bash
   pip install -r requirements.txt
   ```

3. **运行初始化脚本**
   ```bash
   python scripts/init_data.py
   ```

#### 执行结果：
```
✅ 成功导入 12 个站场
✅ 成功导入 11 条管线
```

---

### 方法二：手动导入数据

如果你有自己的数据文件，可以手动导入。

#### 1. 准备数据文件

支持的格式：
- **CSV 文件** - 站场数据和管线数据
- **JSON 文件** - 结构化数据
- **SQL 文件** - 直接执行 SQL 语句

#### 2. 使用 SQLite 命令行工具

```bash
# 进入数据库目录
cd backend/data

# 打开数据库
sqlite3 smartgas.db

# 导入 CSV 文件示例
.mode csv
.import stations.csv stations
.import pipelines.csv pipelines

# 退出
.quit
```

#### 3. 使用 Python 脚本导入

创建自定义导入脚本 `custom_import.py`：

```python
import sys
from pathlib import Path
import json

sys.path.insert(0, str(Path(__file__).parent.parent))

from sqlmodel import Session
from app.database import engine, create_db_and_tables
from app.models import Station, Pipeline

def import_from_json(json_file):
    """从 JSON 文件导入数据"""
    create_db_and_tables()
    
    with open(json_file, 'r', encoding='utf-8') as f:
        data = json.load(f)
    
    with Session(engine) as session:
        # 导入站场
        for station_data in data.get('stations', []):
            station = Station(**station_data)
            session.add(station)
        
        # 导入管线
        for pipeline_data in data.get('pipelines', []):
            pipeline = Pipeline(**pipeline_data)
            session.add(pipeline)
        
        session.commit()
        print(f"✅ 导入完成")

if __name__ == "__main__":
    import_from_json("your_data.json")
```

## 📊 数据库结构

### 表 1: stations (站场表)

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| id | VARCHAR | 站场唯一标识 | "node-001" |
| name | VARCHAR | 站场名称 | "贵阳" |
| type | VARCHAR | 站场类型 | "source", "compressor", "distribution" |
| longitude | FLOAT | 经度 | 106.71 |
| latitude | FLOAT | 纬度 | 26.57 |
| design_pressure | FLOAT | 设计压力 (MPa) | 8.5 |
| status | VARCHAR | 运行状态 | "normal", "maintenance", "fault" |

### 表 2: pipelines (管线表)

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| id | VARCHAR | 管线唯一标识 | "line-001" |
| name | VARCHAR | 管线名称 | "中贵干线 中卫-广元" |
| start_station_id | VARCHAR | 起点站场 ID | "node-001" |
| end_station_id | VARCHAR | 终点站场 ID | "node-003" |
| diameter | INTEGER | 管径 (mm) | 1016 |
| length | FLOAT | 长度 (km) | 580 |
| category | VARCHAR | 管线类别 | "中贵线", "中缅线" |
| status | VARCHAR | 运行状态 | "normal", "maintenance", "fault" |

### 方法 2: 使用 Python 脚本

创建 `check_data.py`：

```python
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent))

from sqlmodel import Session, select
from app.database import engine
from app.models import Station, Pipeline

with Session(engine) as session:
    stations = session.exec(select(Station)).all()
    pipelines = session.exec(select(Pipeline)).all()
    
    print(f"📍 站场总数: {len(stations)}")
    print(f"🔗 管线总数: {len(pipelines)}")
    
    print("\n站场列表:")
    for station in stations[:5]:
        print(f"  - {station.name} ({station.type})")
    
    print("\n管线列表:")
    for pipeline in pipelines[:5]:
        print(f"  - {pipeline.name} ({pipeline.length}km)")
```

运行：
```bash
python check_data.py
```

## 🛠️ 常见问题

### Q1: 数据库文件不存在怎么办？

**A:** 运行初始化脚本会自动创建数据库文件：
```bash
python scripts/init_data.py
```

### Q2: 如何重置数据库？

**A:** 删除数据库文件后重新初始化：
```bash
# Windows
del backend\data\smartgas.db
python backend\scripts\init_data.py

# Linux/Mac
rm backend/data/smartgas.db
python backend/scripts/init_data.py
```

### Q3: 如何备份数据库？

**A:** 直接复制数据库文件：
```bash
# Windows
copy backend\data\smartgas.db backend\data\smartgas_backup.db

# Linux/Mac
cp backend/data/smartgas.db backend/data/smartgas_backup.db
```

### Q4: 如何导入大量数据？

**A:** 使用批量插入提高性能：

```python
from sqlmodel import Session
from app.database import engine
from app.models import Station

# 准备大量数据
stations = [
    Station(id=f"node-{i}", name=f"站场{i}", ...)
    for i in range(1000)
]

# 批量插入
with Session(engine) as session:
    session.add_all(stations)
    session.commit()
```
