# 批量 CSV 导入使用指南

## 📋 第一步:准备 CSV 文件

### 1.1 创建目录(已完成✅)
```
backend/data/raw_csvs/
```

### 1.2 放置你的 CSV 文件

请将以下文件放到 `backend/data/raw_csvs/` 目录:

**必需文件**:
- ✅ `干线管道.csv` - 干线管道数据
- ✅ `支线管道.csv` - 支线管道数据
- ✅ `分输口.csv` - 分输口设施
- ✅ `储气库.csv` - 储气库设施
- ✅ `压缩机.csv` - 压缩机站

**可选文件**:
- `管道站场阀室关系.csv` - 拓扑关系(用于连接管线和站场)

---

## 📋 第二步:检查文件结构

放置文件后,运行:

```bash
cd backend
python scripts/import_batch_csv.py --show-structure
```

**这会显示**:
- 每个 CSV 文件的列名
- 示例数据
- 帮助你确认列名映射是否正确

---

## 📋 第三步:执行导入

确认文件结构后,运行:

```bash
python scripts/import_batch_csv.py --clear
```

**参数说明**:
- `--clear`: 清空现有数据(首次导入建议使用)
- 不加 `--clear`: 追加到现有数据

---

## 📋 第四步:验证结果

导入完成后,验证:

```bash
# 检查数据库
python scripts/check_database.py

# 刷新前端
# 打开浏览器访问 http://localhost:3001
# 按 F5 刷新页面
```

---

## ⚙️ 列名映射配置

如果你的 CSV 列名与脚本预期不同,需要调整映射。

### 站场/设施文件预期列名:
- `分输口名称` / `储气库名称` / `压缩机站名称`
- `经度`
- `纬度`
- `设计压力(MPa)`

### 管线文件预期列名:
- `管道名称`
- `管径(mm)`
- `长度(km)`
- `起点` / `终点`
- `设计压力(MPa)`

**如果列名不同**,告诉我实际的列名,我会帮你调整脚本。
