# 数据格式修改指南

## 🎯 概述

这个工具可以帮你：
- ✅ **格式转换**: CSV ↔ JSON
- ✅ **字段映射**: 重命名字段、统一字段名
- ✅ **数据验证**: 检查数据完整性和正确性
- ✅ **数据清洗**: 添加默认值、修正数据类型

---

## 🚀 快速开始

### 场景 1: Excel 导出的 CSV 转标准格式

假设你从 Excel 导出了一个 CSV 文件，字段名是中文：

**原始文件 (excel_stations.csv):**
```csv
站场编号,名称,类型,经度,纬度,设计压力
S001,成都站,压气站,104.06,30.67,8.5
S002,重庆站,分输站,106.55,29.56,6.0
```

**步骤 1: 转换为 JSON**
```bash
cd backend
python scripts/modify_data_format.py convert --input excel_stations.csv --output temp.json
```

**步骤 2: 映射字段名**
```bash
python scripts/modify_data_format.py map --input temp.json --output standard_stations.json
```

工具会自动将中文字段名映射为标准字段名：
- `站场编号` → `id`
- `名称` → `name`
- `类型` → `type`
- `经度` → `longitude`
- `纬度` → `latitude`
- `设计压力` → `design_pressure`

**步骤 3: 验证数据**
```bash
python scripts/modify_data_format.py validate --input standard_stations.json --type stations
```

**步骤 4: 导入数据库**
```bash
python scripts/import_custom_data.py --json standard_stations.json
```

### 场景 2: 自定义字段映射

如果你的数据字段名不在预定义映射中，可以自定义映射规则：

**原始数据 (custom_format.json):**
```json
[
  {
    "station_code": "S001",
    "station_title": "成都站",
    "category": "compressor",
    "lng": 104.06,
    "lat": 30.67,
    "max_pressure": 8.5
  }
]
```

**自定义映射:**
```bash
python scripts/modify_data_format.py map \
  --input custom_format.json \
  --output mapped.json \
  --mapping '{"station_code":"id","station_title":"name","category":"type","max_pressure":"design_pressure"}'
```

## 🔧 详细功能说明

### 1. 格式转换

#### CSV 转 JSON

```bash
python scripts/modify_data_format.py convert \
  --input stations.csv \
  --output stations.json
```

**自动类型转换:**
- 整数字段自动转为 `int`
- 小数字段自动转为 `float`
- 其他保持为字符串

#### JSON 转 CSV

```bash
python scripts/modify_data_format.py convert \
  --input data.json \
  --output data.csv
```

**嵌套 JSON 处理:**

如果 JSON 包含 `stations` 和 `pipelines`：
```json
{
  "stations": [...],
  "pipelines": [...]
}
```

工具会自动生成两个 CSV 文件：
- `data.csv` (stations)
- `data_pipelines.csv` (pipelines)

---

### 2. 字段映射

#### 使用预定义映射

```bash
python scripts/modify_data_format.py map \
  --input raw_data.json \
  --output clean_data.json
```

#### 自定义映射

```bash
python scripts/modify_data_format.py map \
  --input raw_data.json \
  --output clean_data.json \
  --mapping '{"old_field":"new_field","另一个字段":"another_field"}'
```

#### 禁用预定义映射

```bash
python scripts/modify_data_format.py map \
  --input raw_data.json \
  --output clean_data.json \
  --mapping '{"field1":"new_field1"}' \
  --no-common
```

---

### 3. 数据验证

#### 验证站场数据

```bash
python scripts/modify_data_format.py validate \
  --input stations.json \
  --type stations
```

**验证规则:**
- ✅ 必填字段: id, name, type, longitude, latitude
- ✅ 站场类型: source, compressor, distribution
- ✅ 经度范围: -180 ~ 180
- ✅ 纬度范围: -90 ~ 90
- ✅ 状态枚举: normal, maintenance, fault, disabled

**输出示例:**
```
📊 验证结果:
  总数: 10
  有效: 8
  错误: 2

❌ 错误列表:
  - 站场 3: 缺少必填字段 ['longitude']
  - 站场 5: 无效的类型 'pump'，应为 ['source', 'compressor', 'distribution']
```

#### 验证管线数据

```bash
python scripts/modify_data_format.py validate \
  --input pipelines.json \
  --type pipelines
```

**验证规则:**
- ✅ 必填字段: id, name, start_station_id, end_station_id, diameter, length, category
- ✅ 管径 > 0
- ✅ 长度 > 0
- ✅ 状态枚举: normal, maintenance, fault, disabled

## 💡 实战示例

### 示例 1: 处理 Excel 导出的数据

**场景:** 你从 Excel 导出了站场和管线数据，字段名是中文

**步骤:**

1. **准备数据**

   **stations_excel.csv:**
   ```csv
   编号,站场名称,站场类型,经度,纬度,设计压力
   node-001,成都气源站,source,104.06,30.67,10.0
   node-002,重庆压气站,compressor,106.55,29.56,8.5
   ```

   **pipelines_excel.csv:**
   ```csv
   编号,管线名称,起点,终点,管径,长度,类别
   line-001,成渝干线,node-001,node-002,1016,320,成渝线
   ```

2. **转换和映射**

   ```bash
   # 转换站场数据
   python scripts/modify_data_format.py convert --input stations_excel.csv --output stations_temp.json
   python scripts/modify_data_format.py map --input stations_temp.json --output stations_clean.json --mapping '{"编号":"id","站场名称":"name","站场类型":"type"}'
   
   # 转换管线数据
   python scripts/modify_data_format.py convert --input pipelines_excel.csv --output pipelines_temp.json
   python scripts/modify_data_format.py map --input pipelines_temp.json --output pipelines_clean.json --mapping '{"编号":"id","管线名称":"name"}'
   ```

3. **合并数据**

   手动编辑或使用 Python 脚本合并：
   ```python
   import json
   
   with open('stations_clean.json') as f:
       stations = json.load(f)
   
   with open('pipelines_clean.json') as f:
       pipelines = json.load(f)
   
   data = {
       "stations": stations,
       "pipelines": pipelines
   }
   
   with open('final_data.json', 'w', encoding='utf-8') as f:
       json.dump(data, f, ensure_ascii=False, indent=2)
   ```

4. **验证和导入**

   ```bash
   python scripts/modify_data_format.py validate --input final_data.json --type stations
   python scripts/modify_data_format.py validate --input final_data.json --type pipelines
   python scripts/import_custom_data.py --json final_data.json
   ```

### 示例 3: 添加缺失字段

**场景:** 数据缺少 `status` 字段，需要添加默认值

**Python 脚本:**
```python
import json
from scripts.modify_data_format import FieldMapper

# 读取数据
with open('data.json') as f:
    data = json.load(f)

# 添加默认字段
if 'stations' in data:
    data['stations'] = FieldMapper.add_default_fields(
        data['stations'],
        {'status': 'normal'}
    )

if 'pipelines' in data:
    data['pipelines'] = FieldMapper.add_default_fields(
        data['pipelines'],
        {'status': 'normal'}
    )

# 保存
with open('data_with_status.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

## ⚠️ 常见问题

### Q1: CSV 文件中文乱码怎么办？

**A:** 指定正确的编码：
```bash
python scripts/modify_data_format.py convert --input data.csv --output data.json --encoding gbk
```

常见编码：
- `utf-8` - 标准 UTF-8
- `utf-8-sig` - 带 BOM 的 UTF-8
- `gbk` - 中文 GBK
- `gb2312` - 简体中文

### Q2: 如何处理嵌套的 JSON 数据？

**A:** 工具会自动识别嵌套结构：

```json
{
  "stations": [...],
  "pipelines": [...]
}
```

转换为 CSV 时会生成多个文件。

### Q3: 字段映射不生效？

**A:** 检查：
1. 字段名是否完全匹配（区分大小写）
2. 是否使用了 `--no-common` 禁用了预定义映射
3. 自定义映射的 JSON 格式是否正确

### Q4: 验证失败如何修复？

**A:** 根据错误信息逐个修复：

```bash
# 先验证
python scripts/modify_data_format.py validate --input data.json --type stations

# 根据错误信息修改数据文件

# 再次验证
python scripts/modify_data_format.py validate --input data.json --type stations
```
