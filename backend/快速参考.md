# 🚀 自定义数据导入 - 快速参考

## 📝 一分钟快速上手

```bash
# 1. 生成模板
cd backend
python scripts/import_custom_data.py --export-template

# 2. 编辑模板文件
#    - data_template.json (JSON 格式)
#    - stations_template.csv (站场 CSV)
#    - pipelines_template.csv (管线 CSV)

# 3. 导入数据
python scripts/import_custom_data.py --json data_template.json
```

---

## 📋 常用命令

### 导入数据

```bash
# 从 JSON 导入
python scripts/import_custom_data.py --json your_data.json

# 从 CSV 导入
python scripts/import_custom_data.py --csv-stations stations.csv --csv-pipelines pipelines.csv

# 清空现有数据后导入
python scripts/import_custom_data.py --json your_data.json --clear
```

### 验证数据

```bash
# 检查数据库状态
python scripts/check_database.py
```

### 备份与恢复

```bash
# 备份数据库
copy data\smartgas.db data\smartgas_backup.db

# 恢复数据库
copy data\smartgas_backup.db data\smartgas.db
```

## 📊 数据格式速查

### JSON 格式

```json
{
  "stations": [
    {
      "id": "node-001",
      "name": "站场名称",
      "type": "compressor",          // source | compressor | distribution
      "longitude": 106.71,
      "latitude": 26.57,
      "design_pressure": 8.5,
      "status": "normal"             // normal | maintenance | fault | disabled
    }
  ],
  "pipelines": [
    {
      "id": "line-001",
      "name": "管线名称",
      "start_station_id": "node-001",
      "end_station_id": "node-002",
      "diameter": 1016,
      "length": 580.0,
      "category": "中贵线",
      "status": "normal"
    }
  ]
}
```

### CSV 格式

**stations.csv:**
```
id,name,type,longitude,latitude,design_pressure,status
node-001,站场名称,compressor,106.71,26.57,8.5,normal
```

**pipelines.csv:**
```
id,name,start_station_id,end_station_id,diameter,length,category,status
line-001,管线名称,node-001,node-002,1016,580,中贵线,normal
```

## ⚡ 字段速查表

### 站场字段

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| id | 字符串 | ✅ | 唯一标识 | "node-001" |
| name | 字符串 | ✅ | 站场名称 | "贵阳压气站" |
| type | 字符串 | ✅ | source/compressor/distribution | "compressor" |
| longitude | 数字 | ✅ | 经度 -180~180 | 106.71 |
| latitude | 数字 | ✅ | 纬度 -90~90 | 26.57 |
| design_pressure | 数字 | ✅ | 设计压力 MPa | 8.5 |
| status | 字符串 | ❌ | 运行状态 | "normal" |

### 管线字段

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| id | 字符串 | ✅ | 唯一标识 | "line-001" |
| name | 字符串 | ✅ | 管线名称 | "中贵干线" |
| start_station_id | 字符串 | ✅ | 起点站场 ID | "node-001" |
| end_station_id | 字符串 | ✅ | 终点站场 ID | "node-002" |
| diameter | 整数 | ✅ | 管径 mm | 1016 |
| length | 数字 | ✅ | 长度 km | 580.0 |
| category | 字符串 | ✅ | 管线类别 | "中贵线" |
| status | 字符串 | ❌ | 运行状态 | "normal" |

---

## ⚠️ 注意事项

- ✅ 站场必须先于管线导入
- ✅ ID 必须唯一，不能重复
- ✅ 管线的起点和终点站场必须存在
- ✅ CSV 文件使用 UTF-8 编码
- ⚠️ `--clear` 参数会删除所有现有数据

## 🔍 故障排查

### 问题：导入失败

**检查清单:**
- [ ] 文件路径是否正确
- [ ] JSON 格式是否有效（可用在线工具验证）
- [ ] CSV 文件是否 UTF-8 编码
- [ ] 所有必填字段是否都有值
- [ ] 管线的起点和终点站场是否存在

### 问题：中文乱码

**解决方案:**
- Excel: 另存为 "CSV UTF-8 (逗号分隔)"
- 记事本: 保存时选择 UTF-8 编码

### 问题：数据导入后不显示

**检查步骤:**
```bash
# 1. 验证数据库
python scripts/check_database.py

# 2. 重启后端服务
python run.py
```
