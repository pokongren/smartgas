# 自定义数据导入指南

## 🎯 快速开始

### 第一步：生成模板文件

```bash
cd backend
python scripts/import_custom_data.py --export-template
```

这将生成三个模板文件：
- `data_template.json` - JSON 格式模板
- `stations_template.csv` - 站场 CSV 模板
- `pipelines_template.csv` - 管线 CSV 模板

### 第二步：编辑模板文件

根据你的实际数据编辑模板文件（见下方格式说明）

### 第三步：导入数据

```bash
# 从 JSON 导入
python scripts/import_custom_data.py --json data_template.json

# 或从 CSV 导入
python scripts/import_custom_data.py --csv-stations stations_template.csv --csv-pipelines pipelines_template.csv
```

## 📋 数据格式说明

### JSON 格式

```json
{
  "stations": [
    {
      "id": "node-001",              // 站场唯一标识 (必填)
      "name": "贵阳压气站",           // 站场名称 (必填)
      "type": "compressor",          // 站场类型 (必填): source, compressor, distribution
      "longitude": 106.71,           // 经度 (必填)
      "latitude": 26.57,             // 纬度 (必填)
      "design_pressure": 8.5,        // 设计压力 MPa (必填)
      "status": "normal"             // 运行状态 (可选): normal, maintenance, fault, disabled
    }
  ],
  "pipelines": [
    {
      "id": "line-001",              // 管线唯一标识 (必填)
      "name": "中贵干线",             // 管线名称 (必填)
      "start_station_id": "node-001", // 起点站场 ID (必填)
      "end_station_id": "node-002",   // 终点站场 ID (必填)
      "diameter": 1016,              // 管径 mm (必填)
      "length": 580.0,               // 长度 km (必填)
      "category": "中贵线",           // 管线类别 (必填)
      "status": "normal"             // 运行状态 (可选): normal, maintenance, fault, disabled
    }
  ]
}
```

### CSV 格式

**stations.csv (站场数据):**
```csv
id,name,type,longitude,latitude,design_pressure,status
node-001,贵阳压气站,compressor,106.71,26.57,8.5,normal
node-002,昆明分输站,distribution,102.71,25.04,6.0,normal
node-003,中卫气源站,source,105.18,37.50,10.0,normal
```

**pipelines.csv (管线数据):**
```csv
id,name,start_station_id,end_station_id,diameter,length,category,status
line-001,中贵干线,node-001,node-002,1016,580,中贵线,normal
line-002,中缅线,node-002,node-003,813,450,中缅线,normal
```

## 📊 字段说明

### 站场 (Station) 字段

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| id | 字符串 | ✅ | 站场唯一标识，不能重复 | "node-001" |
| name | 字符串 | ✅ | 站场名称 | "贵阳压气站" |
| type | 字符串 | ✅ | 站场类型 | "source", "compressor", "distribution" |
| longitude | 浮点数 | ✅ | 经度 (-180 ~ 180) | 106.71 |
| latitude | 浮点数 | ✅ | 纬度 (-90 ~ 90) | 26.57 |
| design_pressure | 浮点数 | ✅ | 设计压力 (MPa) | 8.5 |
| status | 字符串 | ❌ | 运行状态，默认 "normal" | "normal", "maintenance", "fault", "disabled" |

### 管线 (Pipeline) 字段

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| id | 字符串 | ✅ | 管线唯一标识，不能重复 | "line-001" |
| name | 字符串 | ✅ | 管线名称 | "中贵干线" |
| start_station_id | 字符串 | ✅ | 起点站场 ID，必须存在于站场表中 | "node-001" |
| end_station_id | 字符串 | ✅ | 终点站场 ID，必须存在于站场表中 | "node-002" |
| diameter | 整数 | ✅ | 管径 (mm) | 1016 |
| length | 浮点数 | ✅ | 长度 (km) | 580.0 |
| category | 字符串 | ✅ | 管线类别 | "中贵线", "中缅线" |
| status | 字符串 | ❌ | 运行状态，默认 "normal" | "normal", "maintenance", "fault", "disabled" |

## ⚠️ 注意事项

### 1. 数据完整性

- ✅ **站场必须先导入**: 管线的 `start_station_id` 和 `end_station_id` 必须存在于站场表中
- ✅ **ID 唯一性**: 每个站场和管线的 ID 必须唯一
- ✅ **坐标范围**: 经度 (-180 ~ 180)，纬度 (-90 ~ 90)

### 2. 数据类型

- 数字字段不要加引号（JSON 中）
- CSV 中的数字会自动转换类型
- 中文字符请使用 UTF-8 编码

### 3. 清空数据

使用 `--clear` 参数会 **删除所有现有数据**，请谨慎使用：

```bash
# ⚠️ 这会删除所有现有数据！
python scripts/import_custom_data.py --json new_data.json --clear
```

建议先备份数据库：
```bash
copy backend\data\smartgas.db backend\data\smartgas_backup.db
```

### 2. 编程方式批量生成数据

```python
import json

# 生成 100 个站场
stations = []
for i in range(100):
    stations.append({
        "id": f"auto-{i:03d}",
        "name": f"自动站场{i}",
        "type": "distribution",
        "longitude": 100 + i * 0.1,
        "latitude": 30 + i * 0.1,
        "design_pressure": 6.0,
        "status": "normal"
    })

# 保存为 JSON
data = {"stations": stations, "pipelines": []}
with open("auto_generated.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 导入
from scripts.import_custom_data import import_from_json
import_from_json("auto_generated.json")
```

## 📞 常见问题

### Q1: 导入时提示 "站场不存在" 怎么办？

**A:** 确保管线的起点和终点站场 ID 在站场数据中存在。建议先导入站场，再导入管线。

### Q2: CSV 文件中文乱码怎么办？

**A:** 确保 CSV 文件使用 UTF-8 编码保存。在 Excel 中另存为 CSV 时，选择 "CSV UTF-8 (逗号分隔)"。

### Q3: 如何只导入站场或只导入管线？

**A:** 
- 只导入站场: JSON 中只包含 `stations` 数组，或只使用 `--csv-stations`
- 只导入管线: JSON 中只包含 `pipelines` 数组，或只使用 `--csv-pipelines`

### Q4: 导入失败如何回滚？

**A:** 如果导入前备份了数据库，可以恢复备份：
```bash
copy backend\data\smartgas_backup.db backend\data\smartgas.db
```
