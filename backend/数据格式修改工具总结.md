### 方法三：在 Python 代码中使用

```python
from scripts.modify_data_format import DataConverter, FieldMapper, DataValidator

# 1. 转换格式
data = DataConverter.csv_to_json('input.csv')

# 2. 映射字段
mapped = FieldMapper.map_fields(data, {
    '中文字段': 'english_field'
})

# 3. 验证数据
valid, errors = DataValidator.validate_stations(mapped)
```

## 🎯 支持的功能

### 1. 格式转换

| 转换方向 | 支持 | 说明 |
|---------|------|------|
| CSV → JSON | ✅ | 自动转换数据类型 |
| JSON → CSV | ✅ | 支持嵌套 JSON |
| Excel → JSON | ✅ | 先导出为 CSV |

### 2. 字段映射

**预定义映射（自动识别）:**
- `编号`, `station_id` → `id`
- `名称`, `station_name` → `name`
- `经度`, `lng`, `lon` → `longitude`
- `纬度`, `lat` → `latitude`
- `设计压力`, `pressure` → `design_pressure`
- 更多... (查看工具源码)

**自定义映射:**
```python
custom_mapping = {
    '你的字段名': '标准字段名',
    'old_field': 'new_field'
}
```

### 3. 数据验证

**站场验证:**
- ✅ 必填字段检查
- ✅ 站场类型枚举 (source/compressor/distribution)
- ✅ 坐标范围验证
- ✅ 状态枚举验证

**管线验证:**
- ✅ 必填字段检查
- ✅ 起点/终点站场存在性检查
- ✅ 数值范围验证 (管径、长度 > 0)
- ✅ 状态枚举验证

### 4. 数据清洗

- ✅ 添加默认字段
- ✅ 自动类型转换
- ✅ 去除无效数据
- ✅ 字段重命名

- ✅ UTF-8 编码支持

### 场景 3: 批量数据清洗

```python
# 读取数据
data = DataConverter.csv_to_json('raw_data.csv')

# 映射字段
mapped = FieldMapper.map_fields(data, custom_mapping)

# 添加默认值
complete = FieldMapper.add_default_fields(mapped, {
    'status': 'normal',
    'region': '默认区域'
})

# 验证并过滤
valid, errors = DataValidator.validate_stations(complete)

# 保存有效数据
save_to_file(valid, 'clean_data.json')
```
