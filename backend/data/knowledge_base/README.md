# 📚 SmartGas Grid 知识库文档存储

## 📁 目录结构

此目录专门用于存放**文档 RAG 库**的原始文档,AI 将自动读取这些文档并向量化存储。

```
knowledge_base/
├── 应急预案/          # 各类应急处置预案
├── 操作规程/          # 日常操作规程文档
├── 维检修手册/        # 设备维护检修手册
├── 技术标准/          # 行业技术标准规范
└── README.md         # 本说明文件
```

## 📝 支持的文件格式

- **Word 文档**: `.docx`, `.doc`
- **PDF 文件**: `.pdf`
- **文本文件**: `.txt`, `.md`
- **Excel 表格**: `.xlsx`, `.xls` (用于操作票等结构化文档)

## 🎯 使用说明

### 1. 添加文档

将文档放入对应的分类文件夹:

- **应急预案**: 超压处置、泄漏应急、火灾应急等
- **操作规程**: 启停机流程、巡检规程、交接班制度等
- **维检修手册**: 压缩机维修、阀门检修、管道维护等
- **技术标准**: GB 标准、行业规范、设计手册等

### 2. 文档命名规范

建议使用清晰的命名,便于 AI 理解:

```
✅ 好的命名:
- 超压应急处置预案.docx
- 压缩机日常巡检规程.pdf
- 球阀维修手册_2025版.docx

❌ 不好的命名:
- 文档1.docx
- 新建文件.pdf
- 未命名.docx
```

### 3. 文档内容建议

为了提高 RAG 检索效果:

- ✅ 使用清晰的章节标题
- ✅ 包含关键词(如"压力异常"、"阀门卡涩")
- ✅ 分段明确,一段一个主题
- ❌ 避免大段无格式文本
- ❌ 避免纯图片扫描件(OCR 效果差)

## 🔄 自动更新机制

- 新增文档后,需要重新运行 RAG 向量化脚本
- 修改文档后,需要重新索引
- 删除文档后,向量库会自动清理

## 🚀 向量化命令

```bash
# 重新索引所有文档
python scripts/build_knowledge_base.py

# 只索引特定分类
python scripts/build_knowledge_base.py --category 应急预案
```
