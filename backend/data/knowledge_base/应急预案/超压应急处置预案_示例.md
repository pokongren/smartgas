# 天然气管网超压应急处置预案

## 一、适用范围

本预案适用于天然气管网系统压力超过设计压力或安全阈值的应急处置。

## 二、压力分级标准

| 压力等级 | 压力范围 | 响应级别 |
|---------|---------|---------|
| 正常 | ≤ 4.0 MPa | 无需响应 |
| 预警 | 4.0 - 4.5 MPa | 三级响应 |
| 警戒 | 4.5 - 5.0 MPa | 二级响应 |
| 危险 | > 5.0 MPa | 一级响应 |

## 三、应急处置步骤

### 三级响应(预警状态)

**压力范围**: 4.0 - 4.5 MPa

1. **立即通知**
   - 通知当班调度员
   - 记录压力数值和时间
   - 启动监控程序,每 5 分钟记录一次

2. **初步排查**
   - 检查压缩机运行状态
   - 检查下游用气量变化
   - 检查调压设备工作状态

3. **预防措施**
   - 准备开启泄压阀
   - 通知维修人员待命
   - 准备应急工具和设备

### 二级响应(警戒状态)

**压力范围**: 4.5 - 5.0 MPa

1. **紧急通知**
   - 立即通知站长和技术负责人
   - 通知上级调度中心
   - 启动应急小组

2. **压力控制**
   - **立即开启泄压阀**,排放压力
   - 降低上游压缩机出口压力
   - 增加下游供气量(如有条件)

3. **设备检查**
   - 检查安全阀是否正常
   - 检查管道有无异常振动
   - 检查法兰连接处有无泄漏

4. **人员安排**
   - 现场人员撤离到安全区域
   - 设置警戒线
   - 准备消防设备

### 一级响应(危险状态)

**压力范围**: > 5.0 MPa

1. **紧急停机**
   - **立即停止上游压缩机**
   - **全开泄压阀**
   - 关闭进气阀门

2. **人员疏散**
   - 立即疏散现场所有人员
   - 设置 500 米警戒区
   - 禁止无关人员进入

3. **应急联动**
   - 通知消防部门
   - 通知安监部门
   - 通知周边居民

4. **持续监控**
   - 远程监控压力变化
   - 记录压力下降曲线
   - 准备抢修方案

## 四、注意事项

### 操作禁忌

- ❌ 禁止在高压状态下进行任何维修作业
- ❌ 禁止使用明火或产生火花的工具
- ❌ 禁止单人操作,必须双人确认

### 安全要求

- ✅ 操作人员必须穿戴防护装备
- ✅ 保持通讯畅通
- ✅ 记录所有操作时间和参数

## 五、恢复操作

压力降至安全范围(< 4.0 MPa)后:

1. 检查设备状态
2. 分析超压原因
3. 排除故障隐患
4. 编写事故报告
5. 逐步恢复供气
