# 数据导入分步指导手册

---

## 🎯 第一步:准备 CSV 数据文件

### 你需要两个 CSV 文件:

#### 1. 站场数据文件 (例如: `my_stations.csv`)
```csv
id,name,type,longitude,latitude,design_pressure,status
station-001,我的站场1,distribution,116.40,39.90,6.0,normal
station-002,我的站场2,compressor,117.20,39.13,8.5,normal
```

**字段说明**:
- `id`: 站场唯一标识(英文+数字)
- `name`: 站场名称(可以用中文)
- `type`: 类型(source/compressor/distribution)
- `longitude`: 经度
- `latitude`: 纬度
- `design_pressure`: 设计压力(MPa)
- `status`: 状态(normal/maintenance/fault)

#### 2. 管线数据文件 (例如: `my_pipelines.csv`)
```csv
id,name,start_station_id,end_station_id,diameter,length,category,status
line-001,我的管线1,station-001,station-002,813,120,测试线,normal
```

**字段说明**:
- `id`: 管线唯一标识
- `name`: 管线名称
- `start_station_id`: 起点站场ID(必须存在于站场文件中)
- `end_station_id`: 终点站场ID(必须存在于站场文件中)
- `diameter`: 管径(mm)
- `length`: 长度(km)
- `category`: 类别
- `status`: 状态

## 🎯 第三步:运行导入命令

### 操作:
```bash
# 确保在 backend 目录
cd backend

# 运行导入命令(替换成你的文件名)
python scripts/import_custom_data.py \
  --csv-stations 你的站场文件.csv \
  --csv-pipelines 你的管线文件.csv \
  --clear
```

**参数说明**:
- `--csv-stations`: 指定站场 CSV 文件
- `--csv-pipelines`: 指定管线 CSV 文件
- `--clear`: 清空现有数据(如果不想清空,去掉这个参数)

### 预期输出:
```
📂 正在读取站场 CSV: ...
  ✅ 成功导入 X 个站场

📂 正在读取管线 CSV: ...
  ✅ 成功导入 X 条管线

✅ 数据导入完成!
```

## ❓ 常见问题

### 问题1: 提示文件不存在
**解决**: 确认文件在 `backend` 目录下,文件名拼写正确

### 问题2: 中文乱码
**解决**: CSV 文件另存为 UTF-8 编码

### 问题3: 导入失败
**解决**: 检查 CSV 格式,确保列名正确

### 问题4: 管线导入失败
**解决**: 确保 `start_station_id` 和 `end_station_id` 在站场文件中存在
