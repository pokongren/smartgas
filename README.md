# 智脉平台 (SmartGas-Grid)

**基于大模型的复杂天然气管网智能调度与决策辅助系统**

![项目架构图占位符](./docs/assets/screenshot_dashboard.png)

## 📌 项目概述
**智脉平台**是一套面向省级/国家级天然气管网运营的新一代智能化指挥辅助系统。项目直击工业调度中**“看不全、查得慢、编得累、算不透”**四大核心痛点，深度融合了**拓扑图数据计算、物理管网仿真、RAG 领域知识库检索**与**多智能体（Agent）工作流**能力。

系统旨在将传统的“被动监控操作型 SCADA 系统”升级为“主动预测与智能辅助决策平台”，大幅度降低一线操作认知负荷，构筑管网本质安全防线。

---

## 🎯 核心解决痛点与业务价值

1. **AI 智能驾驶舱（全景监控视角）**
   - **痛点**：调度管辖范围极大，视图切换割裂，极易形成监控盲区。
   - **方案**：动态组建监控卡片与分屏视图，实现高风险站场与关键核心参数的“主动聚合推优显示”。
2. **自然语言领域检索引擎（NL2SQL + RAG）**
   - **痛点**：海量应急预案与设备台账查询极慢，延误黄金抢险时间。
   - **方案**：基于 MiniMax 大模型与 ChromaDB 向量检索库，支持调度员通过复杂自然语言一秒穿透查询标准处置操作，实现“秒级支持”。
3. **专家级管网调度智能体（Agent & 工作流）**
   - **痛点**：停气保供排产极度依赖老专家的隐性经验，方案手写耗时长、易违规。
   - **方案**：内置管网拓扑规则引擎，一键生成带有冲突检测的安全操作指导步骤，让 AI 承担生成工作，人工仅做最后审核。
4. **多维运行数据洞察与预测支持**
   - **痛点**：数万点位的 SCADA 时序数据沦为“死表”，仅作事后诸葛亮。
   - **方案**：后台 AI 静默监听高频状态偏差，一键成表出图并形成文字剖析诊断报告，向“预测性前瞻”大步迈进。

## 🏗️ 系统技术架构

项目采用前后端分离架构，前端注重图形渲染与组件化交互，后端主打高算力图引擎推演模型及多模型调度能力。

### 技术栈选型
| 层级 | 核心技术选型 | 优势与理由 |
| :--- | :--- | :--- |
| **前端应用** | React 18 + TypeScript + Vite | 极致热更新与严格的工业级前端工程化基础。 |
| **视觉呈现** | Tailwind CSS + Vanilla Canvas | 规避臃肿的三方图表库，实现 3000+ 拓扑节点毫秒级流畅渲染，定制化极强。 |
| **后端核心** | Python 3.12 + FastAPI | 高性能异步处理，原生适配各类深度学习与大模型库生态调用。 |
| **持久层存储** | SQLite + SQLModel | 轻量化部署极简集成，ORM 保证严格数据类型映射。 |
| **AI 驱动层** | LangChain + MiniMax API + Chroma DB | 基于内网级 API 高稳定调用的 RAG 大模型集成，向量化检索引擎。 |
| **物理引擎层** | NetworkX (拓扑算法库) | 高效处理复杂多支路干网流向、断裂影响及高管存计算等拓扑运算。 |

## 🚀 核心功能模块清单

### 1. 基础数据资产与拓扑组态
- **站场/管线资产维护**：实现压气站、分输站、阀室增删改查及 Excel 批量安全导入质检功能。
- **纯 Canvas 力导向图编辑器**：智能发现孤立管网节点、自检错断异常连接；支持大规模节点的极速渲染缩放、拖拽与高亮锁定。
- **流向与介数中心性计算**：自动标记全局核心能源枢纽节点。

### 2. 仿真推理测试沙盘
- **断气延时寿命推演**：结合 Papay 压缩因子与管存物理容量，推演突发断流下管网残存气量可支撑的安全时延。
- **物理流量与阻力模拟**：集成 Panhandle B 公式进行的近似稳态水力流量及压损影响域推演。
- **孤立岛/故障传播推演**：利用自研的图遍历算法实时计算阀门截断后的停气波及面。

### 3. AI 效能助手应用集
- **业务规程极速 RAG 搜索**：全局悬浮式对话操作框，历史运维抢险长文本秒级精准检索响应。
- **场景化排产 Agent 工作流面板**：节点拖拉拽式图形化排产，内置合规拓扑模板避免操作指令“人机冲突”。
- **SCADA UI解耦与智能下钻**：独立悬浮弹出的数据跟踪窗，不再受制于切屏刷新，时刻盯紧告警红线。

## 💻 本地快速部署与启动指南

项目环境配置极简友好（零重度中间件依赖）。

### 1. 启动后端 (Python 端)
```bash
cd backend

# 安装项目依赖 (推荐使用虚拟环境)
pip install -r requirements.txt

# 启动 FastAPI 服务应用
# (应用将运行在 http://localhost:8000，Swagger API 文档地址为 /docs)
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
*(注意：运行 AI 助手功能需确保在根目录 `.env.local` 或环境变量中配有 `MINIMAX_API_KEY` 等大模型密钥及对应设置。)*

### 2. 启动前端 (Node 端)
```bash
# 返回至前台根目录或另开终端
npm install

# 启动 Vite 开发服务器 
# (应用将运行在 http://localhost:3000)
npm run dev
```

### 3. 系统自检快捷支持
在根目录提供了工作流脚本 `/status` 用于自查 `node` 及 `python` 的运行和端口监听状况：
```bash
# 检查默认监听端口
netstat -ano | findstr :3000
netstat -ano | findstr :8000
```

## 📁 目录结构导引
- `backend/app/main.py`: 后端 FastAPI 总入口程序。
- `backend/app/services`: 包括 RAG 引擎 (`rag_enhanced.py`)、图算法推理主心骨 (`topology.py`)。
- `backend/scripts`: 包含离线数据库同步脚本与向量召回数据的处理脚本。
- `src/App.tsx`: 前端视图路由控制大本营。
- `src/views`: 涵盖了拓扑编辑 (`TopologyView.tsx`) 等核心主屏页面。
- `docs/`: 含有系统开发早期的各种算法详细架构推演、数学物理模型推演全记录以及业务痛点剖析赛题提案文件。
