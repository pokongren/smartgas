# 天然气管网拓扑计算方案

## 概述

本方案旨在为 SmartGas 系统提供完整的拓扑计算能力，包括**拓扑提取**、**图算法计算**和**前端可视化**三个核心模块。

## 核心功能模块

### 1. 拓扑提取模块

从数据库提取管网拓扑结构，分离干线与支线。

**输入**: 管线名称 (如 "西气东输二线")
**输出**: 结构化拓扑数据

```json
{
  "pipeline_name": "西气东输二线",
  "trunk": [
    { "id": "st_001", "name": "霍尔果斯压气站", "mileage": 0.0, "type": "compressor" }
  ],
  "branches": [
    [
      { "id": "st_101", "name": "嘉峪关压气站", "mileage": 0.0, "type": "compressor" }
    ]
  ],
  "connections": [
    { "from": "干线", "to": "支线1", "at": "酒泉压气站" }
  ]
}
```

### 2. 图计算模块

基于 NetworkX 实现核心图算法：

| 算法 | 功能 | 应用场景 |
|------|------|----------|
| 最短路径 (Dijkstra) | 计算两站间最短路径 | 备用路由规划 |
| 最小生成树 (MST) | 提取管网骨架 | 简化可视化 |
| 连通分量 | 识别独立管网 | 故障影响分析 |
| 介数中心性 | 识别关键节点 | 风险评估 |
| 环检测 | 识别管网环路 | 调度优化 |

### 3. 物理计算模块

基于真实物理参数的管网计算：

- **管存计算**: 考虑压力、温度、压缩因子
- **流量计算**: 基于 Panhandle B 公式
- **延迟推演**: 断流传播时间估算
- **压力降计算**: 沿程摩阻损失

### 4. 仿真推演模块

基于 Tick 的离散事件仿真：

- 故障传播模拟
- 多故障源推演
- 环网处理
- 恢复策略验证

## API 设计

### 1. 拓扑分析

```http
POST /api/topology/analyze
Content-Type: application/json

{
  "pipeline_name": "西气东输二线",
  "analysis_type": "full"
}

Response:
{
  "node_count": 156,
  "edge_count": 189,
  "connected_components": 1,
  "cycles": 12,
  "critical_nodes": ["霍尔果斯压气站", "中卫压气站"],
  "avg_path_length": 4.5
}
```

### 2. 路径计算

```http
POST /api/topology/path
Content-Type: application/json

{
  "source": "霍尔果斯压气站",
  "target": "上海末站",
  "exclude_pipelines": ["pipe_xxx"]
}

Response:
{
  "path": ["霍尔果斯", "精河", "中卫", ... , "上海"],
  "total_length": 4892.5,
  "estimated_time": "48h",
  "risk_level": "low"
}
```

### 3. 仿真推演

```http
POST /api/topology/simulate
Content-Type: application/json

{
  "failure_nodes": ["中卫压气站"],
  "tick_minutes": 10,
  "max_ticks": 1000
}

Response:
{
  "total_ticks": 156,
  "affected_pipes": 23,
  "frames": [...],
  "ai_summary": "中卫压气站故障将影响..."
}
```

## 前端集成

### useTopology Hook

```typescript
const {
  graph,           // 图实例
  nodes,           // 节点列表
  edges,           // 边列表
  
  // 计算方法
  findPath,        // 路径查找
  findMST,         // 最小生成树
  detectCycles,    // 环检测
  getCentrality,   // 中心性分析
  
  // 仿真方法
  simulateFailure, // 故障仿真
  
  // 状态
  loading,
  error
} = useTopology(pipelineName)
```

## 性能优化

1. **图缓存**: 拓扑结构缓存，避免重复构建
2. **增量更新**: 仅更新变化部分
3. **Web Worker**: 复杂计算移至后台线程
4. **分页加载**: 大规模管网分片加载
