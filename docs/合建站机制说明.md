# 合建站机制说明

## 什么是合建站

合建站是指**两个地理位置相近但分属不同管线系统的站场**，在物理上共用同一站址。合并后，该站场同时连接多条管线，成为管网**枢纽节点**。

---

## 合并流程

以中卫为例：西一线和中贵线各有一个"中卫压气站"，物理位置几乎相同。

### 合并前

```
stations 表:
┌──────────┬────────────┬──────────┬─────────┐
│ ID       │ 名称        │ 经度      │ 纬度    │
├──────────┼────────────┼──────────┼─────────┤
│ WE1-1005 │ 中卫压气站  │ 104.94   │ 37.52   │  ← 保留
│ ZG-2001  │ 中卫压气站  │ 104.95   │ 37.51   │  ← 移除
└──────────┴────────────┴──────────┴─────────┘

pipelines 表:
  盐池 → WE1-1005 → 靖边     （西一线）
  ZG-2001 → 固原 → 天水      （中贵线）
```

管线不互通，各走各的。

### 合并操作

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① | 重命名保留站 | `WE1-1005` → "中卫枢纽站" |
| ② | 管段重定向 | 所有指向 `ZG-2001` 的管段 → 改指 `WE1-1005` |
| ③ | 删除移除站 | `ZG-2001` 从 stations 表删除 |
| ④ | 记录枢纽 | junction_groups 表新增"中卫枢纽站"记录 |
| ⑤ | 清理自环 | 若合并产生 A→A 管段，自动删除 |

### 合并后

```
stations 表:
┌──────────┬────────────┬──────────┬─────────┐
│ ID       │ 名称        │ 经度      │ 纬度    │
├──────────┼────────────┼──────────┼─────────┤
│ WE1-1005 │ 中卫枢纽站  │ 104.94   │ 37.52   │
└──────────┴────────────┴──────────┴─────────┘

pipelines 表:
  盐池 → WE1-1005 → 靖边     （西一线）   ← 不变
  WE1-1005 → 固原 → 天水     （中贵线）   ← 重定向
```

**一个站场现在同时连接了西一线和中贵线**。

---

## 前端操作

1. 进入 **地图拓扑管理** 页面
2. 导入拓扑
3. 操作模式 → 选择 **「合并」**
4. 点击第一个节点（高亮选中）
5. 点击第二个节点
6. 确认合并 → 选择保留哪个站 → 输入新名称
7. 合并完成，地图自动刷新

## API 接口

### 合并站场

```
POST /api/topology/merge-stations
```

请求体：

```json
{
  "keep_station_id": "WE1-1005",
  "remove_station_id": "ZG-2001",
  "new_name": "中卫枢纽站"
}
```

返回：

```json
{
  "message": "合并成功: 中卫压气站 + 中卫压气站 → 中卫枢纽站",
  "kept_station": { "id": "WE1-1005", "new_name": "中卫枢纽站" },
  "removed_station": { "id": "ZG-2001", "name": "中卫压气站" },
  "pipelines_redirected": 2,
  "self_loops_removed": 0
}
```

### 保存坐标

```
PUT /api/topology/station/{station_id}/position
```

```json
{ "longitude": 104.94, "latitude": 37.52 }
```

### 批量保存坐标

```
PUT /api/topology/stations/batch-position
```

```json
{
  "updates": [
    { "id": "WE1-1005", "longitude": 104.94, "latitude": 37.52 },
    { "id": "SJ4-1001", "longitude": 108.79, "latitude": 37.59 }
  ]
}
```

## 数据影响

| 表 | 合并影响 |
|-----|---------|
| `stations` | 保留站重命名，移除站被删 |
| `pipelines` | 移除站的所有管段端点 → 重定向到保留站 |
| `junction_groups` | 新增合建站记录，标记为跨系统枢纽 |

> **注意**：合并操作不可逆。建议操作前先备份数据库。
