#### 具体缺口

1. AI 前端消息目前基本只有纯文本。
2. `subagents` 目前是**提示词工作流编排模式**（格式化任务 JSON 发给 AI 分步执行），不是代码层面的多线程并行 Agent 框架。现阶段完全够用，但要对这个定位有清晰认识，不要误以为是独立进程级别的并行执行体系。
3. 图表组件能复用，但还没有 AI 报告卡片容器。
4. 历史数据接口是"按站/按枢纽取时序"，还没有"多站点横向对比报告接口"。
5. 趋势预测和风险分析能力有基础，但还不够覆盖"水露点 + 多口压力 + 多口温度 + 未来走向 + 风险等级"这一整套诊断报告。
6. **水露点接口三层均未打通**：`ScadaHistory` 模型字段已有 `dewpoint`，但后端历史查询接口、前端图表组件均未支持水露点场景，三层（DB → API → 前端组件）需要专项补齐。
7. **AI 面板布局未规划**：当前 AI 助手是固定宽度浮窗抽屉，趋势图卡片进入聊天区后空间严重不足，必须先确定布局方案再动图表卡片。
2. `subagents` 现在只是提示词里的工作流描述，不是真正可执行的多代理分工体系。
3. 图表组件能复用，但还没有 AI 报告卡片容器。
